# WeChatPort 图形来源

App图标与文档/收集槽图形为本项目独立制作，不复制微信或其他应用素材，适用根目录LICENSE个人非商业许可。

- wechatport-app.svg：彩色品牌矢量源。
- wechatport-mark.svg：单色模板源。
- macos/Resources：由矢量源导出的PNG、ICNS与Asset Catalog。
- WeChatPort.ico：Windows图标资源，不表示Windows程序已实现。

界面通过SwiftUI使用Apple SF Symbols，仅用于Apple平台应用界面，不将其作为品牌图标或导出至Windows。系统图像适用Apple SDK许可：https://www.apple.com/legal/sla/docs/xcode.pdf 。本项目未采用Iconfont第三方图标。
